## 从问题走向实现

这里将收录个人软件项目、研究工具与工程复盘。当前还没有添加真实项目。

> 项目介绍应说明实际解决的问题、实现方式与验证结果。示例模板中的“待补充”不代表已完成的成果。

后续每个项目可以包含：

- 项目名称与一句话简介
- 代码仓库和可运行的演示
- 技术栈、设计取舍与复现步骤
- 有证据支持的结果，以及当前限制

本地项目提供了 `scaffolds/project.md` 模板，可通过 `npm.cmd run new -- project "项目名称"` 创建介绍文章，编辑完成后再展示到本页。
